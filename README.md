# EVEX Website

GitHub Pages-ready EVEX website.

## Upload
Upload the CONTENTS of this folder to the root of your GitHub repository.

Required root files include:
- index.html
- styles.css
- script.js
- assets/
- supporting .html pages
- .nojekyll

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

Do not rename `index.html`.

## Custom domain
After the GitHub Pages staging site works, configure `evextech.ai`.
`CNAME.example` is included as a reference only. Do not rename it to `CNAME` until the domain DNS is being connected.

## Notes
- The dashboard shown on the homepage is conceptual.
- The site avoids fabricated customer logos and case studies.
- Privacy and Terms are draft placeholders requiring legal review.
